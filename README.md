# rust-webapi-axum
A REST Web API in Rust using Axum, PostgreSQL, Redis, and JWT. Based off of the tutorial at https://sheroz.com/pages/blog/rust-axum-rest-api-postgres-redis-jwt-docker.html#configuration

## Git Commands
Amend a commit's author
```shell
git commit --amend --author="New Author Name <new.email@example.com>" --no-edit
```

Set an author for a single git repository
```shell
git config --local user.name "Austin Kaylor"
git config --local user.email "austinjohnkaylor@outlook.com"
```

Verify current author for a single git repository
```shell
git config --local --get user.name
git config --local --get user.email
```
